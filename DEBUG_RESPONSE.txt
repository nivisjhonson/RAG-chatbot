╔══════════════════════════════════════════════════════════════╗
║  COMMON PROBLEMS & WHAT YOU'LL SEE:                          ║
╚══════════════════════════════════════════════════════════════╝

Problem 1: No PDF uploaded
  Log shows: [RAG] Found 0 context chunks
  Log shows: [RAG] No documents found for this user
  Fix: Upload a PDF first

Problem 2: Pinecone connection issue
  Log shows: Error connecting to Pinecone
  Fix: Check PINECONE_API_KEY in .env file

Problem 3: PDF upload failed
  Log shows: Error processing PDF
  Fix: Check if PDF file is valid

Problem 4: Frontend can't reach backend
  Browser console (F12) shows: Network Error
  Fix: Make sure backend is running on port 8000

3. Try asking a question

Common errors:
  - "Network Error" = Backend not running
  - "401 Unauthorized" = Token issue, logout and login again
