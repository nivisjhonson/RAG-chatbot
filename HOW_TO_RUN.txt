========================================
RUN THESE COMMANDS TO START THE APP
========================================

STEP 1: Open Command Prompt (cmd)
Press Windows Key + R
Type: cmd
Press Enter

STEP 2: Copy and paste this command:
cd c:\Users\Dell\Desktop\RAG\backend && python -m uvicorn app:app --reload

Wait for: "Application startup complete"

STEP 3: Open ANOTHER Command Prompt
Press Windows Key + R again
Type: cmd
Press Enter

STEP 4: Copy and paste this command:
cd c:\Users\Dell\Desktop\RAG\frontend && npm start

Browser will open automatically!
