═══════════════════════════════════════════════════════════════
  COMMON ISSUES:
═══════════════════════════════════════════════════════════════

Issue: "Found 0 context chunks"
  → No PDF uploaded or wrong user_id
  → Upload PDF first

Issue: "Pinecone error"
  → Check PINECONE_API_KEY in .env
  → Make sure it's correct

Issue: "Network Error" in browser
  → Backend not running
  → Start backend first

Issue: Response shows but is empty
  → Check if PDF was processed correctly
  → Look for upload errors in logs
