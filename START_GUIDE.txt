## HOW TO USE:

1. Open http://localhost:3000
2. Click "Try as Guest" (or Register/Login)
3. Click "Choose File" and select a PDF
4. Click "Upload" button
5. Wait for "PDF uploaded successfully!"
6. Type question in text box OR click microphone button to speak
7. Click "Send" to get AI answer

## VOICE RECOGNITION:

- Click Send

## TROUBLESHOOTING:

### Backend won't start:
```
cd backend
python test_backend.py
```

### Frontend errors:
```
cd frontend
npm install
npm start
```

### PDF upload fails:
- Check backend is running (http://127.0.0.1:8000)
- Verify PDF file is valid
- Check browser console (F12)

### No chat response:
- Upload PDF first
- Check backend terminal for errors
- Verify Pinecone connection
