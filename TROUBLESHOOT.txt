╔══════════════════════════════════════════════════════════════╗
║  COMMON PROBLEMS & FIXES:                                    ║
╚══════════════════════════════════════════════════════════════╝

Problem: "Python not found"
Fix: Install Python from https://www.python.org/downloads/

Problem: "Node.js not found" or "npm not found"
Fix: Install Node.js from https://nodejs.org/

Problem: "Port 8000 already in use"
Fix: Close other programs or restart computer

Problem: "Port 3000 already in use"
Fix: Close other programs or restart computer

Problem: Backend starts but shows errors
Fix: Check if Pinecone API key is correct in backend\.env

Problem: Frontend shows blank page
Fix: Check browser console (F12) for errors
